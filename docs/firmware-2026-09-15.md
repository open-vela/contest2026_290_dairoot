GitHub Release 的[单附件上限为 2 GiB](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases#storage-and-bandwidth-quotas)，
因此整包经 `gzip -n -6` 无损压缩后分发。请为下载与解压预留至少 7 GB 空间。

Linux / macOS 下载与解压：

```bash
mkdir -p k7-firmware-2026-09-15
cd k7-firmware-2026-09-15
RELEASE_URL=https://github.com/open-vela/contest2026_290_dairoot/releases/download/firmware-2026-09-15
curl -fL --retry 3 -O "$RELEASE_URL/update.img.gz"
curl -fL --retry 3 -O "$RELEASE_URL/amp.img"
curl -fL --retry 3 -O "$RELEASE_URL/SHA256SUMS"
gzip -dk update.img.gz
# Linux：三个文件均应显示 OK
sha256sum -c SHA256SUMS
# macOS 改用：shasum -a 256 -c SHA256SUMS
```

Windows 可用 7-Zip 解压 `update.img.gz`，再在 PowerShell 中执行
`Get-FileHash .\update.img -Algorithm SHA256` 和
`Get-FileHash .\amp.img -Algorithm SHA256`，与下面的完整哈希比较。

## 烧写与软件范围

- **首刷**：使用解压后的 `update.img`，通过 RKDevTool 升级模式或 SDK 的
  `upgrade_tool uf update.img` 烧写。整包会覆盖现有系统及用户数据，先备份。
- **迭代**：只有已经刷过本项目 AMP 整包、存在 `/dev/disk/by-partlabel/amp` 且
  dtb 为 AMP 变体的板子，才能单独更新 `amp.img`。它不能用于原厂固件首刷。
- `amp.img` 小于当前 2 MiB AMP 分区容量；内含 openvela，加载地址
  `0x41800000`，运行于 cpu3。板上心跳版本应为 `0x3`，它仅是协议版本，不能
  替代文件 SHA256 判断具体固件版本。

详细烧写、持久备份及 UART5 / 心跳 / RPMsg 验收步骤见
[板级 README](../board/contest_board/README.md#三复现步骤评委可照做)。

**整包使用厂商预制 Ubuntu rootfs，刷完不等于完整语音助手已部署。**
板上手工安装的下列内容未打入此整包，需另行准备：

  三个独立终端的启动命令及访问地址见
